Check that a file on Serey is intact

Try one:
  1. Step 1

    Paste a link or an ID

    A Serey post link, an S5 file ID, or an Arweave ID. Copy one from a post in the Serey Explorer.

  2. Step 2

    We find every copy

    On S5, Serey's own storage, and on Arweave, where posts saved with Forever are kept for good.

  3. Step 3

    Your browser checks them

    It downloads each copy and compares its fingerprint with the file's. Same fingerprint, same file.
