How a check works

Every file has a fingerprint, worked out from its exact bytes. Change one byte and the fingerprint changes. The drawing here is one fingerprint: two copies of the same file draw the same picture.

On S5
Serey's own storage. Every file has a copy here, and it's the one Serey shows you.
On Arweave
A public network that keeps files forever, with no delete. Posts saved with Forever have a copy here too.

Your browser downloads each copy and works out its fingerprint. Same fingerprint, same file. To check a file you have, pick it from your device; it is never uploaded.
