Verify a file on Serey

Paste a content ID, an Arweave ID, or a post link to check all its files at once.

  1. Step 1

    Copy an ID or a link

    Open a post in the Serey Explorer and copy its link, or an S5 or Arweave ID from Proof of storage.

  2. Step 2

    See where it's stored

    We ask Serey's S5 node, S5 Garden and Arweave where the file is kept.

  3. Step 3

    Verify the bytes

    Your browser hashes the file and compares it with the ID. An Arweave copy is checked against its S5 CID.
