S5 content IDs

Look up and verify any file stored by Serey

Paste a content ID to see what it names, where Serey's S5 node keeps the file, and prove in your browser that the bytes match.

Try an example:

1

Read the ID

A CID is the address of a file, made from the file itself. It names the file's size and its BLAKE3 hash, so nobody can swap a file behind an ID.

2

Find the file

The page asks Serey's S5 node where the file is kept, and asks another S5 node whether it knows the file too.

3

Prove the bytes

Download the file, or pick a copy you have. Its hash is computed right here in your browser and compared with the ID.

Where Serey files live

Images and videos on Serey posts are stored on Serey's own S5 node. Each post in the Serey Explorer lists the content IDs of its files. Nothing you paste here is sent anywhere except to the S5 nodes that answer where a file lives.
