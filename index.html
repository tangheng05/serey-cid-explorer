CID Explorer

What is a CID?

A CID is the address of a file, made from the file itself. Change one byte and the CID changes, so nobody can swap a file behind an ID.

Paste the ID shown on a post in the Serey Explorer. This page reads what the ID says, asks Serey's S5 node where the file is kept, and can download it and prove, right in your browser, that its bytes match the ID.

Nothing you paste is sent anywhere except to the S5 nodes that answer where a file lives.
